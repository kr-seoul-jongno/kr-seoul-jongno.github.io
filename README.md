# 종로구 · 서울특별시

> 종로구 지역 정보 랜딩 사이트

## 🌐 랜딩 페이지

### **https://kr-seoul-jongno.github.io/**

종로구는 서울 도심 한복판에 자리한 자치구로, 조선왕조가 한양에 도읍을 정한 이래 600여 년 동안 나라의 중심 무대 역할을 해온 곳이다. 경복궁을 비롯한 다섯 궁궐과 종묘, 한양도성이 좁은 면적 안에 촘촘히 모여 있어 도시 전체가 하나의 야외 역사 박물관에 가깝다. 정부서울청사와 주요 언론사, 대기업 본사가 광화문 일대에 밀집해 '정치 1번지'라는 별칭으로도 불린다. 인사동의 고미술 거리, 북촌의 한옥 골목, 대학로의 소극장 거리가 저마다 다른 결의 문화를 품고 있어 관광객과 시민이 사시사철 모여든다. 옛 정취와 첨단 업무 기능이 한 걸음 거리에 공존하는 것이 종로만의 매력이다.
